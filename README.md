# مذكراتي — مولّد مذكرات التعليم المتوسط (الجيل الثاني)

منصة لتوليد مذكرات (بطاقات تربوية) للسنوات 1–4 متوسط لجميع المواد، وفق تخطيط مذكرات الجيل الثاني
لوزارة التربية الوطنية الجزائرية، مع تعديل مباشر وتحميل بصيغة **Word (.docx)**.

## المزايا
- 14 مادة × 4 مستويات: العربية، الرياضيات، الفيزياء، العلوم الطبيعية، التاريخ والجغرافيا، التربية الإسلامية،
  التربية المدنية، الفرنسية، الإنجليزية، الأمازيغية، المعلوماتية، التشكيلية، الموسيقية، البدنية.
- قاعدة منهاج قابلة للتعديل: `backend/app/data/curriculum.json` (مقاطع، ميادين، دروس، مراحل الحصة لكل مادة).
- توليد بالذكاء الاصطناعي (Groq · llama-3.3-70b-versatile افتراضياً، أو أي واجهة متوافقة مع OpenAI).
- بدون مفتاح API تعمل المنصة في **وضع القوالب** (هيكل مذكرة كامل يُكمله الأستاذ).
- معاينة قابلة للتعديل بنفس تخطيط الورقة: ترويسة (رقم المذكرة/المقطع/الميدان/المحتوى المعرفي/الأسبوع/الزمن/الأستاذ/القسم)،
  الكفاءة والأهداف والوسائل، جدول المراحل – الزمن – سير النشاطات – التقويم.
- ملف Word بالاتجاه الصحيح: من اليمين لليسار للعربية، ومن اليسار لليمين للفرنسية والإنجليزية؛ الإجابات بعد «ج:» بالأزرق.
- «ولّد المقطع كاملاً» + «ملف المذكرات»: تجميع عدة مذكرات في ملف Word واحد (فاصل صفحة بين كل مذكرة).
- حفظ معلومات الأستاذ (الاسم، المتوسطة، القسم…) في المتصفح.

## التشغيل محلياً

```bash
# 1) الخادم
cd backend
pip install -r requirements.txt
export GROQ_API_KEY=gsk_...            # اختياري — بدونه يعمل وضع القوالب
uvicorn app.main:app --reload --port 8000

# 2) الواجهة (وضع التطوير)
cd frontend
npm install
npm run dev                            # http://localhost:5173 (يحوّل /api إلى :8000)
```

### نشر كتطبيق واحد
```bash
cd frontend && npm run build && rm -rf ../backend/static && cp -r dist ../backend/static
cd ../backend && uvicorn app.main:app --host 0.0.0.0 --port 8000
```
FastAPI يخدم الواجهة المبنية من `backend/static`. أو استعمل `Dockerfile` الموجود في الجذر.

## متغيرات البيئة
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `GROQ_API_KEY` أو `LLM_API_KEY` | — | مفتاح النموذج |
| `LLM_BASE_URL` | `https://api.groq.com/openai/v1` | أي واجهة OpenAI-compatible |
| `LLM_MODEL` | `llama-3.3-70b-versatile` | اسم النموذج |
| `VITE_API_URL` (الواجهة) | فارغ | عنوان الخادم إن كان على نطاق آخر |

## واجهة API
- `GET /api/curriculum` — المستويات والمواد والمقاطع والدروس.
- `POST /api/generate` — `{level, subject, sequence, lesson, domain?, notes?, teacher?, school?, class_name?, week?, memo_number?, duration?, school_year?}` ← مذكرة JSON.
- `POST /api/export` — `{memos: [...]}` ← ملف `.docx`.

## المخططات السنوية الرسمية المدمجة (سبتمبر 2022)
| المادة | المستويات | ما أُدمج |
|---|---|---|
| اللغة العربية | 1–4 م | 1–3 م: 8 مقاطع لكل مستوى بقواعدها وتقنيات الإنتاج الكتابي الرسمية؛ 4 م: 8 مقاطع: المستويات المستهدفة، الموارد (منطوق/مكتوب/بلاغة/نحو النص/نحو الجملة/إنتاج كتابي)، المهمات، معايير التقويم، توزيع 11+2 حصة |
| الرياضيات | 1–4 م | 28 مقطعاً بهيكلة الموارد المعرفية الرسمية (كل مورد = درس)، الكفاءات الختامية والشاملة، سيرورة المقطع |
| الفرنسية | 1–4 AM | 28 séquence: savoir-faire, ressources linguistiques, indicateurs, déroulement 12 h + 2 h |
| التربية الإسلامية | 1–4 م | 96 درساً موزعة على الفصول الثلاثة بميدانها الرسمي وعناصرها، المستوى المستهدف لكل فصل، الكفاءة الشاملة والختامية |
| العلوم الفيزيائية | 1–4 م | 14 مقطعاً: الكفاءة الختامية والموارد المعرفية (كل مورد = درس)، المشروع التكنولوجي وسيرورة المقطع |
| علوم الطبيعة والحياة | 1–4 م | 21 مقطعاً بالترقيم الرسمي (I-1، II-2…)، موزعة على الفصول، مع الكفاءات الشاملة والختامية |
| التاريخ والجغرافيا | 1–4 م | 6 مقاطع لكل مستوى (3 تاريخ + 3 جغرافيا) بالوضعيات التعلمية الرسمية ووضعيات الإدماج الجزئي |
| التربية المدنية | 1–4 م | 3 مقاطع لكل مستوى بالوضعيات التعلمية الرسمية |
| المعلوماتية | 1–4 م | الميادين والمقاطع التعلمية بحجمها الساعي ومواردها |
| الإنجليزية | MS1–MS4 | 16 sequence: exit profile, target competencies, situations PDP/PPU/integration، ومقتطف المخطط الرسمي لكل sequence |

سكربتات البناء في `backend/app/data/*_official.py` (تُعيد كتابة الأجزاء المعنية في `curriculum.json`).
عند وجود مرجع رسمي يُمرَّر كاملاً للنموذج مع تعليمة الالتزام بصياغته، وتظهر في الواجهة شارة «مطابق للمخطط السنوي الرسمي».

## ملاحظة على المنهاج
المواد والمستويات غير المذكورة في الجدول أعلاه (الأمازيغية، التشكيلية، الموسيقية، البدنية)
ما زالت مبنية على قائمة مرجعية غير رسمية؛ أضف مخططاتها السنوية بنفس الطريقة.

## الأمان
لا تضع مفتاح Groq داخل الكود أو المستودع؛ مرّره كمتغير بيئة `GROQ_API_KEY` (أو في ملف `.env` مستثنى من git).
